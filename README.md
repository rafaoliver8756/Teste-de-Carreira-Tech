# 🧭 Teste de Carreira Tech

Um quiz interativo que ajuda o usuário a descobrir qual área da tecnologia mais combina com o seu perfil: **Front-end**, **Back-end**, **Dados** ou **Design/UX**.

## 💡 Sobre o projeto

O usuário responde 5 perguntas rápidas sobre gostos e formas de resolver problemas. A cada resposta, o sistema soma pontos para a área correspondente e, ao final, mostra qual perfil teve mais pontuação ou se houve empate entre duas ou mais áreas.

Esse projeto foi feito para praticar lógica de programação com JavaScript puro (sem frameworks), manipulação do DOM e estilização com CSS.

## 🚀 Funcionalidades

- Tela de boas-vindas com botão para iniciar o teste
- 5 perguntas de múltipla escolha (radio buttons)
- Cálculo automático da pontuação por área
- Exibição do resultado final, com tratamento de empate
- Efeitos de hover e seleção visual

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox, seletor `:has()`)
- JavaScript (manipulação de DOM, eventos, objetos)

## 📚 Aprendizados

Durante esse projeto, pratiquei:
- Manipulação de `display` para alternar entre telas
- Uso de objetos JavaScript para contar pontuação
- Debug de erros comuns (temporal dead zone, redeclaração de variáveis)
- Aprendi a usar `:hover` para criar interatividade nos botões, e a suavizar essas mudanças com `transition` — algo que eu ainda não tinha praticado antes e deixou a experiência bem mais fluida
